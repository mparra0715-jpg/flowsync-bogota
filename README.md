# FlowSync Bogotá — Tablero MVP

## Qué incluye
- Controles para velocidad, densidad, intensidad de frenado y cantidad de vehículos.
- Representación esquemática de vehículos en dos carriles.
- Indicadores y alerta de riesgo bajo, medio o alto.
- Estimación ambiental ilustrativa con supuestos editables.

## Ejecutar en computador
1. Instala Python.
2. Abre una terminal en esta carpeta.
3. Ejecuta: `pip install -r requirements.txt`
4. Ejecuta: `streamlit run app.py`
5. Abre la dirección local que aparece en la terminal.

## Publicar en internet
1. Crea un repositorio en GitHub y sube `app.py` y `requirements.txt`.
2. Entra a https://share.streamlit.io e inicia sesión con GitHub.
3. Selecciona **Create app**.
4. Elige el repositorio, la rama `main` y el archivo `app.py`.
5. Pulsa **Deploy**.

Los datos y fórmulas son ilustrativos; no es un sistema conectado a tráfico real ni un modelo predictivo validado.
